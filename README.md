# 七夜online

手机端个人工作台，用于日常记录、计划与资产管理、股票和基金行情查看，支持语音和文字录入。

[打开工作台](https://qiyeonline.cc.cd/)

## 本地运行

```bash
npm ci
npm run dev
```

访问 [localhost:3000](http://localhost:3000)。
