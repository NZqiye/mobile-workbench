# 旅行图标目录

核对日期：2026-11-07。来源：[Thiings](https://www.thiings.co/things)（目录版本：`066f16a0db0e`）与项目独立绘制的景点矢量图。

目前共 121 个可选条目，对应 121 张不同的本地图案：85 张 Thiings 透明 WEBP 与 36 张项目绘制的透明 SVG。原有 100 张 Thiings 资源仍保留，供原城市默认图及其他既有引用使用。

国内山水24项、国内古建12项置于中国地标之后，每个景点拥有独立图案。绘制源文件为 `scripts/build-china-landmarks.cjs`，生成目录为 `public/assets-icons/china-landmarks/`。保留已有海外、自然和出行图标及原有保存ID。

使用路径：资产记录 → 旅游记录 → 添加或编辑 → 更换旅行图标；每个景点也可单独选图。选择器默认收起，点击“使用自动匹配”可恢复默认图案。自选图标随记录保存，纳入现有同步和备份。

国内图案按各景点的地形、建筑轮廓及标志性特征绘制，属于简化矢量图，并非实景照片。例如西湖采用三潭印月，洱海采用苍山与白族民居，泸沽湖采用独木舟，青海湖采用油菜花岸线；大雁塔、黄鹤楼、龙门石窟、云冈石窟分别绘制不同轮廓。图标名称只显示景点名字，自动匹配采用对应的新图案。23个新增国内城市/地区的预设景点保持可用，城市留空时也能按目的地名称匹配。

Thiings 官网当前说明：单张图标可免费下载用于个人用途，商业使用提供独立授权。本目录记录原始来源，供这套个人工作台使用。

注：官网 `london-bridge` 条目的图片呈现伦敦塔桥，界面按图片标为“伦敦塔桥”。
