# 旅行图标目录

核对日期：2026-11-07。来源：[Thiings](https://www.thiings.co/things)，目录版本：`066f16a0db0e`。

新增 64 张，旅行专用图标共 72 张，分为 5 组。本地透明 WEBP 合计 1520.3 KiB，新增图片最大 320 × 320 像素。

使用路径：资产记录 → 旅游记录 → 添加或编辑旅行 → 更换旅行图标；每个景点也有独立的“更换”入口。分类选择器默认收起，点击“使用自动匹配”可恢复城市或景点的默认图案。自选图标随记录保存，纳入现有同步和备份。

自动匹配优先使用明确地标；没有专用素材的城市使用通用山水、园林或城市图案，并在城市预览中注明。未支持的城市保留行李箱默认图标。通用建筑和自然图案是示意插图，不是地点实景。

Thiings 官网当前说明：单张图标可免费下载用于个人用途，商业使用提供独立授权。本目录记录原始来源，供这套个人工作台使用。

注：官网 `london-bridge` 条目的图片实际呈现伦敦塔桥，因此界面按图片标为“伦敦塔桥”；普通伦敦桥不会自动匹配到这张图。
