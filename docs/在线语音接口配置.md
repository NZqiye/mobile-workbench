# 语音录入与配置

整理日期：2026-11-07。

## 使用

在首页天气下方点击“开始录音”，说完点击“停止并保存”；也可直接输入文字，点击“保存到各栏目”。录音与已有文字合并，完整识别后直接保存，有缺项时提示补充或确认保存已识别部分。

支持饮水、饮食、运动、体重、任务、习惯、观影、资产、订阅、旅行、纪念日、星光计划、生活记录、基金和指数追踪。

- “今天早上9点半喝了300毫升水”：记录饮水量及明确时刻。
- “今天体重65公斤，跑步30分钟”：分别写入体重和运动。
- “完成读书任务”：匹配已有任务并标为完成。
- “看到《某剧》第二季第八集”：补齐片单中该作品第二季的1至8集。
- “看了《某剧》第二季第八集”：只记录这一集。

观看记录须匹配已有片单作品。没有明确季数时沿用当前季或唯一一季；同名作品、季数不明或集数超出范围时提示补充，保留既有进度和评分。

保存后可查看对应栏目或撤销本次记录。草稿在刷新和跨页后保留，全部保存成功才清空；刷新后不保留撤销凭据。更新已有记录时使用完整名称，遇到同名或缺少字段时需要补充。

## 配置

服务使用 Cloudflare Workers AI，转写模型为 `@cf/openai/whisper-large-v3-turbo`，文字归类模型为 `@cf/qwen/qwen3-30b-a3b-fp8`。

在 Cloudflare 的 **Workers AI → Use REST API** 获取 Account ID，并创建带 Workers AI Read / Edit 权限的专用 Token。将 [语音配置模板](../.env.voice.example) 填入本地 `.env.local`，部署时在 Vercel 配置同名变量并重新部署：

```dotenv
CLOUDFLARE_ACCOUNT_ID=你的32位AccountID
CLOUDFLARE_API_TOKEN=你的WorkersAI专用Token
```

线上录入需要先在设置中登录个人账号，密码和会话密钥见 [部署与配置](部署与配置.md)。仅在开发模式、未配置有效会话密钥且通过回环地址访问时，语音接口允许直接使用本地配置。

安卓安装版通过原生麦克风在App内录音，不会打开另一个系统录音机；拒绝权限后的恢复、后台取消与在线服务的边界见[复刻指南](复刻指南与踩坑记录.md#5-手机能力数据和提醒的注意点)。

## 限制与保存规则

- 录音最长 60 秒、文件最大 3MB；浏览器须支持 MediaRecorder 并允许麦克风，页面运行在 HTTPS 或本机 localhost 下。
- 只将本次录音和文字发送给 Cloudflare，已有记录在本机匹配。服务额度与价格以 [Cloudflare 官方说明](https://developers.cloudflare.com/workers-ai/platform/pricing/) 为准。
- 服务未启用时，本地文字规则仅支持饮水和运动，须确认后保存；已连接的在线请求失败时保留原文，不自动降级写入。
- 未明确说明的时刻、运动类型或热量不自行推测。未完成事项不会记成已完成。
- 基金买卖须说明金额、份额和成交净值中的至少两项；此功能只记录已发生的交易。阴历日期在纪念日页面选择。

## 验证

相关自动测试及浏览器保存、查看、撤销和草稿恢复检查通过。真实 Cloudflare 接口已验证合成中文音频和多类文字记录；实体手机麦克风、口音与长语句仍需在实际设备上验证。

接口为 `/api/voice/transcribe`（转写与服务检查）和 `/api/voice/records`（文字归类）。官方接入说明见 [REST API 与 Token 配置](https://developers.cloudflare.com/workers-ai/get-started/rest-api/)。
