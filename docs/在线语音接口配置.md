# 在线语音接口配置

核实日期：2026-11-05。

配置状态：Cloudflare专用Token已创建，仅允许当前账户的Workers AI读写。两项凭据已保存到本地`.env.local`和Vercel项目`mobile-workbench`的Production环境，均不提交Git。正式网址：[七夜online](https://qiyeonline.cc.cd/)。

## 当前接入

服务：Cloudflare Workers AI。

语音转写模型：`@cf/openai/whisper-large-v3-turbo`。

文字理解模型：`@cf/qwen/qwen3-30b-a3b-fp8`。两个模型使用同一组Cloudflare凭据，共享Workers AI的免费额度。

“语音快速记录”只放在“今日速看”主页。点击“开始录音”，允许麦克风权限，说完后点击“停止并填写”。每次最多60秒，录音文件最多3MB。也可使用手机输入法语音填入文字，点击“识别并填写”。

服务端先将录音发送到Cloudflare转写，再将本次文字发送到Qwen填写各模块的草稿。已有记录的名称匹配和修改在本地完成，不发送整个历史库。主页显示记录去向、日期、数量或金额等结果，核对后点击“确认保存”。缺失、歧义或无法匹配的事项显示提示；只保存明确且通过校验的项目。

保存复用原有本地存储、云同步、统计及对应宠物奖励。每条结果提供“查看”按钮，直接进入相应页面和子栏目。返回主页仍能撤销最近一次批量记录；刷新页面后撤销凭据不保留。如果本批记录已被后续修改或删除，会提示到对应页面调整，不覆盖后续修改。

## 免费额度

Cloudflare 官方价格页当前注明：Workers Free 和 Paid 账户每天均有10,000 Neurons免费额度。Whisper转写也消耗这份额度；其他Workers AI模型会共享额度。它不是10,000次请求。

维持 Workers Free 计划时，超过免费额度会失败，需要等额度恢复；使用 Paid 计划时，超出部分可能计费。为了按免费额度使用，本接入不要求升级Paid计划，也不替用户开通付费服务。

官方重置时间是00:00 UTC，对应北京时间每天08:00。平台可能调整政策，以账户控制台为准。

## 需要配置的两个值

1. 在Cloudflare控制台进入 **Workers AI → Use REST API**。
2. 复制 **Account ID**。
3. 通过 **Create a Workers AI API Token** 创建Token。使用官方模板；官方文档要求Workers AI Read与Edit权限。
4. 本地开发时，将仓库中的`.env.voice.example`两项填入`.env.local`。
5. Vercel部署时，将同名变量填入项目 **Settings → Environment Variables**，然后重新部署。

```dotenv
CLOUDFLARE_ACCOUNT_ID=你的32位AccountID
CLOUDFLARE_API_TOKEN=你的WorkersAI专用Token
```

这两个变量只由服务端读取，不使用`NEXT_PUBLIC_`前缀。不要把Token发到聊天窗口或提交进Git。工作台的访问码和会话密钥仍按现有方式配置；使用录音前需要在设置中解锁工作台。

## 联动范围与例子

| 模块 | 支持的记录与更新 |
| --- | --- |
| 饮食 | 饮水量；餐次、食物及明确热量 |
| 运动 | 运动类型、时长、已说明的距离、热量、乒乓球比分 |
| 体重 | 按日期补记；同一天沿用原记录更新，不重复建条 |
| 每日安排 | 新增任务、完成已有任务；新增习惯、按日习惯打卡 |
| 观影 | 想看与已看作品、电影评分、剧集季数和集数；关联观影打卡 |
| 资产 | 购买新物品；已存在物品的出售、退役与备注更新 |
| 订阅 | 会员费用、周期和到期日；续费及使用说明更新 |
| 旅行 | 旅行日期、目的地和费用；在已有旅行中追加景点打卡及评价 |
| 纪念日 | 阳历生日、纪念日、节日、倒计时及日期更新 |
| 星光计划 | 目标、目标日期；在目标中新增或完成具体项目 |
| 生活记录 | 生活、饮食笔记、树洞、复盘、灵感等记录 |
| 基金 | 加入自选；记录已发生的买卖、份额和金额；支付宝持仓校准 |
| 指数追踪 | 加入指数或基金追踪；更新观察阈值和备注 |

- “今天早上9点半喝了一杯水”：今天09:30，250ml。
- “昨天喝了两杯水”：昨天500ml；不编造时刻。
- “今天晚上运动了半小时”：今天，时间段“晚上”，30分钟；记录为“运动”，不推断跑步或乒乓球，不估算热量。
- “今天晚上8点健身30分钟”：今天20:00，健身30分钟。
- “今天体重130斤”：65kg，更新今天的体重记录。
- “完成读书任务”：匹配已有“读书”任务并标为完成。
- “午餐吃面条500千卡”：新增午餐热量记录，不自行推测未知热量。
- “看了测试剧第1季第2和第3集”：追加对应季的实际看过集数，保留已有进度。
- “旧手机今天卖了100元”：匹配“旧手机”资产，更新售出状态、日期和价格，保留购买信息。
- “给读十本书目标增加读第一本项目”：向已有目标追加打卡项目。
- “9点半喝了一杯水”：提示补充早晚。
- “明天打算跑步半小时”“我还没喝水”：不会记录为已完成。

输入可包含多种记录，模型按事项分开填写。未知、同名或缺字段的事项需要补充；已有记录匹配使用完整名称，不做模糊覆盖。阴历日期须在纪念日页面选择；基金交易须明确金额、份额、成交净值中的两项，不能用当前估值替代成交价。基金功能仅记录个人持仓，不实际交易。

未配置凭据、未解锁或在线理解失败时，仅保留饮水和运动的本地文字规则；其他内容会明确提示需要在线服务，不静默丢弃。不涉及删除记录、账户配置、真实下单或外部平台操作。

本次文字理解会消耗Qwen的额度；手机输入法语音可以节省Whisper转写消耗，但仍需文字理解额度才能联动全部模块。

录音要求浏览器支持`MediaRecorder`、允许麦克风，且页面运行在HTTPS或本机localhost环境。配置缺失、额度耗尽或连接失败时，界面保留文字录入路径。

## 验证情况

本次开发已完成以下验证：

- 29项自动测试全部通过，覆盖全部16种记录操作分类、中文记录解析、否定语句、更新保留、批量撤销、季集进度、基金买卖、上传限制和模型响应校验，包括真实结构化响应及用户文字中的模板分隔符。
- 最终生产构建通过，包含`/api/voice/transcribe`与`/api/voice/records`接口。
- 本地HTTP验证覆盖未登录、已登录、缺少供应商配置和跨源请求。
- 浏览器使用模拟模型响应，一次填写并保存16类记录；逐项查看了生活笔记、订阅、旅行、目标项目、体重、饮食热量、运动、纪念日、习惯、任务、观影、资产、基金和指数追踪，均可在对应页面看到保存结果，语音入口只在主页出现。
- 跨页返回主页后撤销整批记录成功；任务、饮食、观影计数与对应奖励恢复。原有饮水500ml和运动30分钟的批量保存、撤销测试也已通过。
- 桌面1280px与手机390px布局检查通过，未出现水平溢出，录入按钮高度44px。新版主页截图保存在`.impeccable/review/voice-home-desktop.png`和`.impeccable/review/voice-home-mobile.png`，截图使用本地模拟接口。

2026-11-05已通过真实Cloudflare接口验证：Token状态有效；Whisper将合成中文语音“我今天早上九点半喝了一杯水，晚上运动了半个小时”正确转为文字；Qwen提取09:30、250ml饮水和晚上30分钟运动。另一段文字同时提取饮水、运动、65kg体重、次日买菜任务和生活笔记，均通过字段校验，没有写入正式记录。

真实联调发现Qwen默认模板会重复输出JSON，已改用官方聊天模板并关闭思考，采用官方建议的非思考采样参数。用户原文里的尖括号按JSON Unicode转义，避免被解释为模板分隔符；仍保留JSON模式、字段白名单和原文校验。

全部16类记录的浏览器保存及撤销验证使用本地模拟响应；真实接口验证覆盖上述5类事项。手机麦克风、不同口音和长语句的效果需要在实际设备上继续观察。
