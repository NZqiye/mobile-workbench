# 纪念日图标目录

更新日期：2026-11-07。图标来源：[Thiings](https://www.thiings.co/things)。新增素材目录版本 `066f16a0db0e`。

使用方法：在「每日安排 → 岁时纪往 → 添加日子」中展开「日子图标」选择。已有记录可点击卡片左上角图标更换。按钮只显示图片，保留分组、选中状态和无障碍名称；选中状态使用主题色描边，不遮挡图案。图标只改变展示，不改变记录类型或日期。

卡片底色、倒数数字、进度条和选中状态跟随当前工作台主题，正文使用主题深色文字。「添加日子」位于标题下方、分类筛选上方。新建倒计时可填写真实起始日期，用于计算日期进度；旧倒计时没有起始日期时显示目标日期，不生成百分比。公历周期事件按上一次至下一次的自然日计算，农历记录暂不显示进度百分比。
