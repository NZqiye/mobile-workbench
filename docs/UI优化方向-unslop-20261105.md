# 七夜online UI 优化审查与方向

日期：2026-11-05。当前状态：根据用户后续反馈，恢复原先风格、角色图标和8种主题的完整配色变化。保留天气下方录音、手打、分类保存及草稿修复；尚未发布线上。下方审查及九层变更为前一轮历史记录，其中统一纸白风格已撤回。

技能：unslop，作者 Damir Sokolovsky（[@heydamir](https://x.com/heydamir)），CC BY 4.0。本文采用其审查清单和分层优化流程，保留此署名。

## 审查范围与证据

本机运行的现有 Next.js 项目。检查首页、每日安排、资产记录和股市行情；前三页同时检查 390×844 手机视口和 1440×1000 桌面视口。

此次审查只使用独立浏览器，不改用户数据。项目内已有的录音、手打归类及保存修复均作为既有功能保留。

截图位于 `output/playwright/unslop-before-{today,plans,assets}-mobile.png` 与 `unslop-before-{today,plans,assets,market}-desktop.png`。

实际样式值位于 `output/playwright/unslop-audit-values.json`。本轮为 unslop 第 1 次批量渲染检查；实施后最多再检查两轮。

## 发现的问题

- 颜色占据整个界面：`.phone-shell` 与 `.content` 实际背景为 `rgb(220,229,227)`，卡片为 `rgb(232,239,237)`；背景、导航、输入框和边框都泛绿，主次不明确。
- 卡片阴影过重：`.panel` 使用两层阴影，包含 `0 12px 28px rgba(30,43,60,.12)`；普通静态内容呈现为浮动窗口。
- 装饰性模糊过多：`.panel` 使用 `blur(10px)`，`.side-nav` 使用 `saturate(1.8) blur(28px)`；这些效果没有帮助用户完成记录。
- 导航过于抢眼：侧栏、底栏和模块标题重复使用彩色角色图，天气使用另一类彩色图标，功能按钮又采用 SVG、emoji 或文字符号，视觉语言不统一。
- 功能按钮使用 emoji：宠物操作中的小蛋糕、奶茶、摸头和电影票使用 emoji，和其他按钮的图标不一致；保留宠物角色本体，功能符号改为同一套线性图标。
- 字重普遍偏高：首页选中导航实测 900，主页标题为 700，模块标题为 720；标签、标题、数量容易同时抢占注意力。
- 字体处理不一致：金句来源用斜体，说明和标签存在较小字号，部分小字同时加粗；应统一正文、说明和数字的层级。
- 间距不统一：首页 `.content` 实际间隔为 14px，其他模块为 10px，侧栏为 14px；内外分组关系需要统一到 4px 步进。
- 圆角过度：导航项圆角为 18px，多种筛选、日期、刷新和总览按钮呈胶囊状；普通行、控件和卡片的形状不易区分。
- 桌面首页留白失衡：时钟、天气和金句卡高度受布局拉伸，文字较少但占据较大空间；顶部占高，真正的任务与统计被推后。
- 卡片嵌套过多：天气中的温度、预报和穿搭，资产中的总览、添加入口和空状态形成多层卡片；应更多依靠对齐、留白与细分隔线分组。
- 数字格式不一致：资产页同时出现 `¥0`、`¥0.00/天`、`每日均降 ¥0.00`，行情则混用价格和带正号的百分比；应按数据语义统一精度，并采用等宽数字。
- 重复信息偏多：顶栏、日期条和页面内多处重复显示时间/日期；刷新状态、来源、解释文本需要降低权重，保留有用信息。
- 操作文字需要保持明确：当前已修复的“保存到各栏目”“未保存”“去设置解锁”等含义必须保留，不能因缩短文案再次隐藏写入动作或失败状态。

CSS 中还存在多轮主题覆盖和循环动画定义。未在本轮各截图中呈现的旧规则仅作为实施定位线索，不将源码命中直接当成用户可见缺陷；只修改实际生效且与本请求有关的样式。

## 判断

多种问题横跨颜色、图标、字重、间距和组件，因此适合运行完整 unslop 分层优化。保留青绿色作为强调色、七夜online 名称、宠物角色、现有内容、功能、栏目顺序和实际数据。

这是可操作的个人工作台，不使用营销首屏或新增生成图片来占据内容空间。视觉亮点来自已有宠物、天气内容与行情数字；不增加虚构统计或装饰图表。

## 已确认的五行方向

1. **产品**：为自己记录生活、安排任务、查看资产和行情的手机优先工作台。
2. **性格**：沉稳、亲切、利落。
3. **世界**：纸页和石墨笔的日常手账；背景接近中性纸白，文字用石墨灰，保留少量青绿色强调。
4. **亮点**：保留胖咕嘎作为生活陪伴的视觉焦点；行情页以真实价格、变化和对齐的数据呈现重点，其他区域保持安静。
5. **识别细节**：手账页码式的日期标记，在今日、打卡和记录时间中使用一致的刻度与数字排版。

## 实施范围

共享导航、页头、按钮、输入框、卡片、表格、空状态及各栏目中实际生效的视觉规则；手机优先，同时完善桌面信息密度。各页功能、数据模型、业务处理及栏目阅读顺序保持现状。

按顺序完成：间距 → 颜色 → 图标 → 文案 → 字体 → 布局 → 细节 → 内容视觉 → 动效。

初始数值：4px 间距步进；手机边距16px；桌面边距24–32px；桌面侧栏240px；常规可触控按钮44px；输入字号16px；正文14–16px；说明12–14px；字重400/500与少量600；控件圆角8–10px，卡片12–16px。最终值需结合实际布局和中文可读性。

保留主题选择这一现有功能，实施时检查如何将各主题的颜色约束为强调色和内容重点，不直接移除主题。

## 验证标准

- 首页天气下方同时可见录音、手打及保存入口；成功与失败状态清楚。
- 各栏目入口和子栏目可正常打开；内容、新增、编辑、查看、撤销流程可用。
- 手机390px、桌面1440px布局不发生横向溢出、遮挡或过度缩小。
- 对实际生效的背景、文字、图标、间距和字体进行批量检查；不得只检查源码。
- 可交互元素具有清楚的选中、禁用和键盘焦点状态；动画遵循减少动态效果偏好。
- 运行与变更相关的检查，并完成生产构建。

## 九层改动记录

以下为前一轮记录，用户随后明确要求保留原先风格与主题变化，因此已撤回全局视觉覆盖，仅保留录入功能与可用性修复。

1. 间距：共享页面采用 4px 步进，手机边距16px、桌面32px，卡片内边距16–20px，分组间距12–20px。
2. 颜色：纸白背景 `#f7f7f5`、白色卡片与石墨文字 `#242724`；主题色用于选中项、主操作和有意义的数据。黑白主题保留深色背景与浅色主按钮。
3. 图标：根据用户后续反馈，恢复原有角色导航、路飞头像、栏目图标及饮水、宠物物资等功能图标；调整图标容器尺寸与对齐，保留用户原有视觉偏好。快速录音按钮继续使用麦克风图标，没有新增图标依赖。
4. 文案：首页简化为“生活、计划与行情，记在一起”；输入提示缩短，保留保存、未保存、解锁和不完整录入提示。
5. 字体：中文系统字体、400/500字重与少量600标题；输入16px，数字统一等宽。金句保留宋体阅读感，资产与订阅金额统一两位小数。
6. 布局：桌面240px导航与流动内容；首页时钟/天气并列，快速记录占较大列、金句占较小列，手机按原有顺序纵向排列。
7. 细节：卡片16px、控件8px圆角；减少嵌套底色与胶囊，补齐焦点和禁用状态。修正旧样式造成的浅色记录文字、编辑和删除按钮。
8. 内容视觉：胖咕嘎、真实天气及行情仍承载内容重点，没有加入生成图片、虚构数据或装饰图表。
9. 动效：移除功能图标和宠物静止状态的循环动画；保留操作反馈，颜色过渡160ms、菜单200ms，并支持减少动态效果偏好。

前一轮覆盖样式集中在 `app/workbench-ui.css`。根据用户反馈，现已删除该覆盖层及其导入；原始 `app/globals.css` 保持未修改，主题背景、卡片、按钮、字体、圆角与效果恢复原样。
