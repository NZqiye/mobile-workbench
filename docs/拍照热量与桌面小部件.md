# 拍照热量与桌面小部件

更新日期：2026-11-08。安卓安装版：1.1.6。

## 拍照识别热量

1. 在“饮食记录 → 热量统计”选择早餐、午餐、晚餐或加餐。
2. 点“拍照”打开手机系统相机；拍完回到App预览。也可以“选择照片”从相册选一张图片。
3. 点“识别食物”，联网估算照片中的食物、份量和各项热量。
4. 点“填入下方记录”，检查食物名称和千卡数字，必要时修改。
5. 点原有的“添加早餐热量”等按钮，才真正保存到饮食记录。

没有清晰食物、服务失败或超时会提示重试，不会自动保存。照片是估算依据，无法精确称重或确认油、糖与酱料含量；结果不是营养检测值。拍摄整份餐食并尽量让餐盘大小清楚，有助于判断份量。

### 数据边界

- 只有点“识别食物”才上传本次照片，既有饮食、笔记和其他历史不会随照片发送。
- 上传前在本机压缩并重新绘制，服务端实际解码、限制尺寸并再次编码，去除EXIF/定位元数据。
- Cloudflare Workers AI执行视觉识别，使用服务端现有凭据与`@cf/meta/llama-4-scout-17b-16e-instruct`。线上需要登录原有个人账号，接口拒绝跨站请求。
- 原图不加入饮食记录、云同步、备份或应用数据库。系统相机使用应用私有临时缓存，取消、应用销毁或下一次启动时清理；服务端仅在本次请求中处理图片。
- 选图允许25MB以内可解码图片，本机转换成JPEG且最长边不超过1024像素；服务器接收上限2MB，拒绝SVG、无法解码和多帧图片。

## 添加桌面小部件

覆盖安装1.1.6后，先打开一次App，让本机数据更新到小部件。然后长按手机桌面空白处，选择“小部件/桌面插件”，找到“七夜online”，拖入需要的小部件。原有今日计划与喝水进度继续可用。

| 小部件 | 显示内容 | 点击后的页面 |
| --- | --- | --- |
| 今日计划 | 今日待办数量和最多三条计划，默认4×2格 | 每日安排 → 计划安排 |
| 喝水进度 | 已喝杯数、每日目标和毫升数，默认2×2格 | 饮食记录 → 喝水打卡 |
| 影视今日更新 | 最多三部片名、季数和更新集数，今日部数/集数，默认4×3格 | 观影记录 → 追剧日历 |
| 资产记录 | 在用物品购入总金额、数量和最近两件在用物品，默认4×3格 | 资产记录 → 我的资产 → 服役中 |

小部件可调整大小。任务完成、饮水记录/目标改变、本机收到云同步以及新一天都会更新显示；App关闭时使用最近一次同步的本机快照，系统另按小部件更新周期刷新。它们不会持续联网或在后台自行拉取电脑端修改。电脑改过记录后，打开手机App同步即可。

不同品牌手机对“小部件”的入口、格数和调整尺寸支持不同。若列表没有出现，确认已经覆盖安装1.1.6，打开App一次，再返回桌面重试。

### 影视与资产小部件

影视排期使用片单里已同步的逐集播出日期，或手工填写的下次更新日期与集数。过滤已看完、暂停/弃剧和归档条目，同一部剧同一天多集更新合并成一行；没有准确排期时不猜测固定周更时间。App在手机上打开后每天自动刷新一次既有TMDB追剧信息，也可以在追剧日历点“刷新更新”。

本机保存未来14天的简要排期，系统按小部件更新周期切换当天，重启、时间变化和覆盖升级时也刷新本机显示。因此App关闭后仍能使用已经同步的未来排期，不需要把账号凭据存入小部件或后台联网。排期超过同步范围会提示打开App；日期已变化时显示排期同步日期。平台临时改档或电脑端修改片单后，需要打开手机App刷新，不保证桌面实时获知改档。

资产金额与App“我的资产”的统计口径一致：只汇总“服役中”物品的购入价格，不计入已出售、退役物品，也不作为银行余额、股票持仓或当前市值。最近物品按购买日期排列；新增、编辑、删除和云同步后更新小部件。没有在用物品时显示空状态。

小部件只接收显示需要的短文字、数量、金额及日期，保存在应用私有本机存储；不会传入完整备注、保修信息、海报地址或其他历史记录。

1.1.6已通过197项自动检查、18项正式预览交互检查和安卓编译/签名检查；检查包括逐集排期、多集去重、跨年日期、统计筛选、冷启动跳转、资产增删改与排期刷新同步。没有连接安卓真机，桌面尺寸、大字体展示及厂商省电策略仍需实际安装确认。
