# 拍照热量与桌面小部件

更新日期：2026-11-08。安卓安装版：1.1.7。

## 拍照识别热量

1. 在“饮食记录 → 热量统计”选择早餐、午餐、晚餐或加餐。
2. 点“拍照”打开手机系统相机；拍完回到App预览。也可以“选择照片”从相册选一张图片。
3. 点“识别食物”，联网估算照片中的食物、份量和各项热量。
4. 点“填入下方记录”，检查食物名称和千卡数字，必要时修改。
5. 点原有的“添加早餐热量”等按钮，才真正保存到饮食记录。

没有清晰食物、服务失败或超时会提示重试，不会自动保存。照片是估算依据，无法精确称重或确认油、糖与酱料含量；结果不是营养检测值。拍摄整份餐食并尽量让餐盘大小清楚，有助于判断份量。

### 数据边界

- 只有点“识别食物”才上传本次照片，既有饮食、笔记和其他历史不会随照片发送。
- 上传前在本机压缩并重新绘制，服务端实际解码、限制尺寸并再次编码，去除EXIF/定位元数据。
- Cloudflare Workers AI执行视觉识别，使用服务端现有凭据与`@cf/meta/llama-4-scout-17b-16e-instruct`。线上需要登录原有个人账号，接口拒绝跨站请求。
- 原图不加入饮食记录、云同步、备份或应用数据库。系统相机使用应用私有临时缓存，取消、应用销毁或下一次启动时清理；服务端仅在本次请求中处理图片。
- 选图允许25MB以内可解码图片，本机转换成JPEG且最长边不超过1024像素；服务器接收上限2MB，拒绝SVG、无法解码和多帧图片。

## 添加桌面小部件

覆盖安装1.1.7后，先打开一次App，让本机数据更新到小部件。然后长按手机桌面空白处，选择“小部件/桌面插件”，找到“七夜online”，拖入需要的小部件。添加后再打开App一次，缓存影视海报。已有小部件会沿用原入口与数据，刷新后使用新样式。

| 小部件 | 显示内容 | 点击后的页面 |
| --- | --- | --- |
| 今日计划 | 深色卡片、待办大数字、任务列表与已完成数，默认4×2格 | 每日安排 → 计划安排 |
| 喝水进度 | 浅蓝卡片、水瓶图标、杯数/目标与进度条，默认2×3格 | 饮食记录 → 喝水打卡 |
| 影视今日更新 | 浅紫海报列表、季集信息和今天/剩余天数，默认4×4格，可滚动 | 观影记录 → 追剧日历 |
| 资产记录 | 深蓝物品卡、陪伴天数、日均成本、总金额和日均下降，默认4×4格 | 资产记录 → 我的资产 → 服役中 |

小部件可调整大小。任务完成、饮水记录/目标改变、本机收到云同步以及新一天都会更新显示；App关闭时使用最近一次同步的本机快照，系统另按小部件更新周期刷新。它们不会持续联网或在后台自行拉取电脑端修改。电脑改过记录后，打开手机App同步即可。

不同品牌手机对“小部件”的入口、格数和调整尺寸支持不同。若列表没有出现，确认已经覆盖安装1.1.7，打开App一次，再返回桌面重试。旧版尺寸较小的资产、喝水与计划小部件使用紧凑布局，拉大可展示完整信息；影视列表按可用高度滚动。

### 影视与资产小部件

影视排期使用片单里已同步的逐集播出日期，或手工填写的下次更新日期与集数。过滤已看完、暂停/弃剧和归档条目，同一部剧同一天多集更新合并成一行；没有准确排期时不猜测固定周更时间。App在手机上打开后每天自动刷新一次既有TMDB追剧信息，也可以在追剧日历点“刷新更新”。

本机保存未来14天的简要排期，展示每部剧最近一次已知更新，按播出日期排列并合并当天多集；“今天”用暖金色突出，未来更新显示还有几天。最多保留60部可滚动条目，长片名省略，海报缺失时用片名首字占位。系统按小部件更新周期切换当天，重启、时间变化和覆盖升级时也刷新本机显示。因此App关闭后仍能使用已经同步的未来排期，不需要把账号凭据存入小部件或后台拉取排期。排期超过同步范围会提示打开App；日期已变化时显示排期同步日期。平台临时改档或电脑端修改片单后，需要打开手机App刷新，不保证桌面实时获知改档。

资产卡默认展示最近购入的一件在用物品，点击右上角齿轮可选其他物品，也可选“资产总览”。每个桌面卡片单独记住所选物品，可以添加多个并展示不同物品。点击卡片主体进入我的资产。已选物品删除、出售或退役后会提示重新选择，不会悄悄换成另一件。

陪伴天数按北京时间的日历日期计算，购买当天计第1天；日均成本=购入价格/陪伴天数，日均下降=今天日均成本−下一天日均成本。例如2026-10-31购入74元的物品，2026-11-08显示9天、日均8.22元、日均下降0.82元。缺少购买日期或购买日期尚未到来时不编造成本值。

资产总览金额与App“我的资产”的统计口径一致：只汇总“服役中”物品的购入价格，不计入已出售、退役物品，也不作为银行余额、股票持仓或当前市值。最近物品按购买日期排列；新增、编辑、删除和云同步后更新小部件。没有在用物品时显示空状态。

小部件只接收显示需要的短文字、数量、金额、日期、物品ID和图像路径，保存在应用私有本机存储；不会传入完整备注、保修信息、模型或登录凭据。物品图标从App内置资源读取。已有影视小部件时，App同步触发短时间海报缓存任务；只访问明确允许的TMDB/Bangumi/TVmaze等公开图片域名，限制下载大小、尺寸和重定向，保存96×144的小图，不转发登录Cookie或其他记录。桌面周期刷新和列表滚动只读本机缓存，海报获取失败不影响片名与倒计时。
