# 安卓安装与打包

更新日期：2026-11-06。

## 安装

从 [GitHub 下载页](https://github.com/NZqiye/mobile-workbench/releases/tag/android-v1.1.0) 下载 `qiyeonline-1.1.0.apk`，在安卓手机上打开安装。首次安装时，按系统提示允许当前浏览器或文件管理器“安装未知应用”；安装完成后可关闭该权限。

已经安装 1.0.0 的手机直接覆盖安装即可，保留原有本地记录和登录状态；不要先卸载。1.1.0 沿用同一应用标识和正式签名。

最低系统版本为安卓 8.0。应用名称为“七夜online”，应用标识为 `cc.qiyeonline.workbench`。

安装后在“设置”解锁云同步，即可同步电脑上的记录、自选股和观察股。安装版使用独立的本地存储，不会自动读取浏览器已有记录；未开启云同步的数据可通过 JSON 备份导入。

## 功能与范围

安装版通过系统 WebView 打开 [线上工作台](https://qiyeonline.cc.cd/)，沿用网页端的统计图表、股价走势、自选股和观察股。网站更新后，重新打开应用即可使用新版本，无需每次重新安装 APK。

- App 固定使用手机布局，底部保留“首页 / 安排 / 录入 / 股市 / 更多”五个入口。横屏也保持手机布局。
- 首页优先展示快速录入和今日任务，时钟缩小，五天天气预报按需展开；保留原有角色图标和八种主题。常用按钮和表单增加触摸空间。
- 1.1.0 直接调用安卓麦克风录音，采用 AAC / m4a 格式；首次开始时请求麦克风权限。拒绝后可点“开启麦克风权限”进入系统应用设置，仍可文字录入。
- 录音在应用内完成，不会打开另一个系统录音机 App。说完点“停止并保存”后联网识别并写入对应栏目；最多录音 60 秒，切到后台会取消本次录音。
- 使用在线识别前需要在“设置”解锁服务。未解锁时点击录音会引导到设置，服务连接失败时可重试，输入的文字草稿会保留。
- 备份导入使用系统文件选择器，导出使用系统“保存文件”窗口。
- 外部链接交给浏览器；返回键先收起键盘、菜单或编辑界面，再返回首页，首页确认退出。键盘展开时底部导航隐藏，系统状态栏和导航栏留出空间。
- 网络连接失败时提供“重新连接”；行情、语音和云同步需要联网。首次打开必须联网，不能把该 APK 当作完整离线版。
- 本版不提供原生锁屏推送。原有网页后台提醒可继续使用浏览器安装的 PWA。

## 构建

此安装版只使用 Android SDK 和 JDK，不新增前端框架。安装 JDK 17、Android SDK Platform 36 和 Build Tools 36.0.0，设置 `JAVA_HOME`、`ANDROID_HOME`，在项目根目录运行：

```bash
npm run build:android
```

生成文件位于 `output/android/qiyeonline-1.1.0.apk`，文件名自动读取清单版本号，同目录的 `SHA256SUMS.txt` 可校验文件完整性。Windows 的 Android 工具不可靠地支持中文路径，构建脚本会在系统临时目录完成编译，再将安装包复制回项目。

第一次构建会在 `.android-signing/` 生成正式签名和本地密码文件，该目录已被 Git 忽略。请单独备份整个目录，后续更新必须使用同一签名，并增加 `AndroidManifest.xml` 中的 `versionCode`、`versionName`。不要将签名或密码上传到 GitHub。

## 验证记录

已完成 Android SDK 编译、APK v2/v3 签名校验和清单检查。109 项自动测试通过，包括原生通信的开始、停止、取消、权限拒绝恢复和 m4a 转写保存；备份导出覆盖了即时撤销 Blob 地址、文件名保留、普通链接、重复初始化和过大文件提示。

浏览器使用隔离数据和模拟的安卓通信通道，检查手机布局、首页录入顺序、天气展开、栏目导航、主题、返回和键盘状态。这些检查验证网页与原生通道的衔接，不等于真实麦克风硬件验收。

本次没有连接安卓真机，因此录音权限、系统文件窗口、键盘与返回键仍需安装后在手机上验收。
