# 安卓安装与打包

更新日期：2026-11-06。

## 安装

从 [GitHub 下载页](https://github.com/NZqiye/mobile-workbench/releases/tag/android-v1.0.0) 下载 `qiyeonline-1.0.0.apk`，在安卓手机上打开安装。首次安装时，按系统提示允许当前浏览器或文件管理器“安装未知应用”；安装完成后可关闭该权限。

最低系统版本为安卓 8.0。应用名称为“七夜online”，应用标识为 `cc.qiyeonline.workbench`。

安装后在“设置”解锁云同步，即可同步电脑上的记录、自选股和观察股。安装版使用独立的本地存储，不会自动读取浏览器已有记录；未开启云同步的数据可通过 JSON 备份导入。

## 功能与范围

安装版通过系统 WebView 打开 [线上工作台](https://qiyeonline.cc.cd/)，沿用网页端的统计图表、股价走势、自选股和观察股。网站更新后，重新打开应用即可使用新版本，无需每次重新安装 APK。

- 录音时请求麦克风权限；拒绝后仍可文字录入。
- 备份导入使用系统文件选择器，导出使用系统“保存文件”窗口。
- 外部链接交给浏览器；返回键返回网页历史，没有历史时确认退出。
- 网络连接失败时提供“重新连接”；行情、语音和云同步需要联网。首次打开必须联网，不能把该 APK 当作完整离线版。
- 本版不提供原生锁屏推送。原有网页后台提醒可继续使用浏览器安装的 PWA。

## 构建

此安装版只使用 Android SDK 和 JDK，不新增前端框架。安装 JDK 17、Android SDK Platform 36 和 Build Tools 36.0.0，设置 `JAVA_HOME`、`ANDROID_HOME`，在项目根目录运行：

```bash
npm run build:android
```

生成文件位于 `output/android/qiyeonline-1.0.0.apk`，同目录的 `SHA256SUMS.txt` 可校验文件完整性。Windows 的 Android 工具不可靠地支持中文路径，构建脚本会在系统临时目录完成编译，再将安装包复制回项目。

第一次构建会在 `.android-signing/` 生成正式签名和本地密码文件，该目录已被 Git 忽略。请单独备份整个目录，后续更新必须使用同一签名，并增加 `AndroidManifest.xml` 中的 `versionCode`、`versionName` 和脚本中的 APK 文件名。不要将签名或密码上传到 GitHub。
