# 安卓安装与打包

更新日期：2026-11-07。

## 安装

从 [GitHub 下载页](https://github.com/NZqiye/mobile-workbench/releases/tag/android-v1.1.3) 下载 `qiyeonline-1.1.3.apk`，在安卓手机上打开安装。首次安装时，按系统提示允许当前浏览器或文件管理器“安装未知应用”；安装完成后可关闭该权限。

已经安装旧版的手机直接覆盖安装即可，保留原有本地记录和登录状态；不要先卸载。1.1.3 沿用同一应用标识和正式签名。

最低系统版本为安卓 8.0。应用名称为“七夜online”，应用标识为 `cc.qiyeonline.workbench`。

安装后在“设置 → 账号登录”使用与电脑相同的个人账号，即可同步记录、自选股和观察股。原项目默认账号为 `qiye`，原使用者的密码沿用原访问码；独立复刻者应自行配置账号密码，没有公开默认密码。安装版使用独立的本地存储，不会自动读取浏览器已有记录；未同步的数据可通过工作台导出的 Markdown 导入，也兼容旧版 JSON 备份。

## 功能与范围

安装版通过系统 WebView 打开 [线上工作台](https://qiyeonline.cc.cd/)，沿用网页端的统计图表、股价走势、自选股和观察股。网站更新后，重新打开应用即可使用新版本，无需每次重新安装 APK。

- App 固定使用手机布局，底部保留“首页 / 安排 / 录入 / 股市 / 更多”五个入口。横屏也保持手机布局。
- 首页优先展示快速录入和今日任务，时钟缩小，五天天气预报按需展开；保留原有角色图标和八种主题。常用按钮和表单增加触摸空间。
- 2026-11-07 网页更新：时钟居中显示时、分、秒；设置页统一账号登录与同步，移除重复的“自选资产”“手机同步”区块。观影评分调整封面、长集名、勾选及电影评分布局，分时图下方不再显示提示小字。现有 1.1.0 重新打开即可加载此次更新，无需安装新 APK。
- 1.1.0 直接调用安卓麦克风录音，采用 AAC / m4a 格式；首次开始时请求麦克风权限。拒绝后可点“开启麦克风权限”进入系统应用设置，仍可文字录入。
- 录音在应用内完成，不会打开另一个系统录音机 App。说完点“停止并保存”后联网识别并写入对应栏目；最多录音 60 秒，切到后台会取消本次录音。
- 使用在线识别前需要在“设置”登录账号。未登录时点击录音会引导到设置，服务连接失败时可重试，输入的文字草稿会保留。
- 备份导入使用系统文件选择器，导出使用系统“保存文件”窗口。
- 设置中的“导出 Markdown / 导入 Markdown”同时用于阅读与完整恢复。请保留文件末尾的完整恢复数据；修改阅读正文不会改变恢复记录，普通 Markdown 笔记不能当作完整备份导入。
- 电视剧“为你推荐”横向单排显示；手机录音按钮与快速记录标题齐平，长片名换行，观影滚动开销减少。此次为网页更新，现有 1.1.0 重新打开即可加载。
- 1.1.1 的返回键先收起键盘、菜单或编辑界面，再返回首页；首页再次返回直接退到后台，不弹退出确认。录音中仍提醒是否放弃当前录音。外部链接交给浏览器；键盘展开时底部导航隐藏，系统状态栏和导航栏留出空间。
- 退到后台保留最近任务入口，不代表应用持续运行；没有新增常驻服务，安卓系统可以回收后台应用。切到后台仍会取消未保存录音，需先停止并保存。
- 本次影视界面更新整理推荐卡片、动漫海报和评分片单，修正滑动时预估高度改变页面长度的问题；网页改动重新打开即可加载，退出行为需升级到 1.1.1。
- 网络连接失败时提供“重新连接”；行情、语音和云同步需要联网。首次打开必须联网，不能把该 APK 当作完整离线版。
- 1.1.3 新增安卓本地任务到时通知：设置中开启“消息提醒”，允许系统通知；可发送测试通知，点击通知进入“每日安排 → 计划安排”。网页后台提醒仍可通过支持推送的浏览器接收。
- 浏览器提醒依赖服务器推送配置、通知权限及订阅；线上配置接口已确认可用。目前服务器每天北京时间 10:00 和 15:00 检查到期任务，并非分钟级即时提醒。

## App 任务提醒

安装 1.1.3 后，在“设置 → 消息提醒”开启并允许系统通知。为未完成任务设置提醒时间后，会自动把本机任务同步到安卓闹钟服务。后台、锁屏或网络断开时，已安排的提醒由系统发送，无需网页常驻运行。可点“发送测试通知”检查手机通知栏；安卓 12 及以上可另行允许“闹钟和提醒”权限以尽量准时，未允许时系统可能延迟。

这是本地到时通知，未接入 FCM 或其他服务器即时远程推送。电脑新增、修改或完成任务后，手机需要打开 App 同步，才会更新本机安排。提醒时间按北京时间解释。删除、完成、取消提醒时间会移除本机安排；同一任务同一时间只提醒一次，过去 24 小时内错过的提醒可在恢复时补发。重启手机和覆盖升级后重新安排；系统强行停止应用后需重新打开，厂商省电策略也可能影响到达时间。

观影评分中的观看进度采用每段40集列表，支持输入集数后“跳到该集”或“已看到这集”，后一操作补齐本季此前集数，保留更后面的已有记录。2026-11-07网页更新后，勾选、取消、全选和“已看到这集”自动保存，无需手动保存进度；定位、展开图片和简介不改变观看状态。评分输入完整后仍需点“保存本季评分”。

## 应用更新

2026-11-08 网页更新：想法笔记统一使用透明背景的熊图标；首页鲸鱼娘、六种奖励、获得奖励增加幸福值、人物图标交换，以及此前的界面和动效修改均共用线上版本。此次更新将网页缓存升至 v11，使用新图标文件名避免沿用旧图。保存当前输入后，从手机最近任务中关闭 App，再联网重新打开即可加载；无需重新安装，也无需清除应用数据。检查已覆盖浏览器中的安卓布局与线上资源，未连接手机进行真机验收。

1.1.2 打开后自动检查版本，每天最多一次；设置的“应用更新”可随时手动检查。发现新版本后可选择“下载更新”或“稍后”。下载进度可以收起，下载完成后由安卓系统确认安装；首次需要按引导允许七夜online“安装未知应用”，返回后继续安装。拒绝权限、取消安装或网络失败不会卸载旧版，仍可继续使用；错误时可手动重试。

1.1.1 及更旧版本需要先手动覆盖安装 1.1.2，之后才具备 App 内检查和下载功能。网页改动仍在重新打开时加载，不依赖 APK 更新。该功能不需要账号登录，不会静默覆盖安装，也没有新增常驻后台服务。

版本清单位于线上 `/app-update.json`，只包含版本、版本代码、官方 GitHub APK 地址、SHA-256 和更新说明。下载仅允许 HTTPS 官方发布地址及 GitHub 资源跳转，完成后验证哈希、应用标识、版本代码和当前签名；通过临时只读内容地址授权给系统安装程序，不开放私人记录文件。

## 构建

复刻自己的版本需要先替换首页可信域名、更新清单地址、GitHub下载校验和应用标识。逐文件替换清单、初始化环境与发布顺序见[复刻指南](复刻指南与踩坑记录.md#3-打包自己的安卓app时必须替换什么)。只运行构建脚本会得到连接原站点的安装包；自己的新签名也不能直接覆盖原作者签名的App。

此安装版只使用 Android SDK 和 JDK，不新增前端框架。安装 JDK 17、Android SDK Platform 36 和 Build Tools 36.0.0，设置 `JAVA_HOME`、`ANDROID_HOME`。工具下载、SDK Manager安装、许可确认及Windows路径示例见[复刻指南的构建环境部分](复刻指南与踩坑记录.md#31-构建环境)。准备完成后，在项目根目录运行：

```bash
npm run build:android
```

生成文件位于 `output/android/qiyeonline-1.1.3.apk`，文件名自动读取清单版本号，同目录的 `SHA256SUMS.txt` 可校验文件完整性。构建同时生成 `output/android/app-update.json` 和 `public/app-update.json`，填写公开版本与 APK 哈希。发布时检查并修改更新说明，将 APK 与哈希文件发布到匹配的 `android-v版本号` GitHub Release，再部署最新公开清单；避免清单指向未发布的安装包。Windows 的 Android 工具不可靠地支持中文路径，构建脚本会在系统临时目录完成编译，再将安装包复制回项目。

第一次构建会在 `.android-signing/` 生成正式签名和本地密码文件，该目录已被 Git 忽略。请单独备份整个目录，后续更新必须使用同一签名，并增加 `AndroidManifest.xml` 中的 `versionCode`、`versionName`。不要将签名或密码上传到 GitHub。

## 验证记录

1.1.2 已完成 Android SDK 编译、APK v2/v3 签名校验，版本代码为 4，沿用原证书。更新校验以真实 Java 运行测试覆盖官方地址、HTTPS、版本清单和被修改的文件；原生消息测试确认更新状态不会干扰录音。浏览器检查覆盖当前版本显示、检查中禁用、失败重试、旧版下载入口和手机尺寸。

浏览器使用隔离数据和模拟的安卓通信通道，检查手机布局、首页录入顺序、天气展开、栏目导航、主题、返回和键盘状态。这些检查验证网页与原生通道的衔接，不等于真实麦克风硬件验收。

本次没有连接安卓真机，因此录音权限、系统文件窗口、键盘与返回键仍需安装后在手机上验收。
