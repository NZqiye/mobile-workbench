# 1.1.11 提醒与纪念日卡片

更新日期：2026-11-27。版本代码 13；沿用原应用标识与签名。安装包与校验文件见[正式发布页](https://github.com/NZqiye/mobile-workbench/releases/tag/android-v1.1.11)。

## 手机提醒

更新后打开“设置 → 消息提醒”，点“开启提醒”，允许系统通知，再发一条测试通知。首页在未开启时也提供入口。原先默认关闭，且仅接入待办，是此前看不到其他模块通知的直接原因；是否还受具体手机权限及省电影响，需要在手机上检查。

| 分类 | 发送时间 |
| --- | --- |
| 待办 | 未完成任务设置的提醒时间 |
| 追剧 | 已知排期的播出时间；未注明时间为当日 20:00 |
| 纪念日 | 前一天与当天 09:00，支持公历与农历 |
| 订阅及话费 | 提前三天与当天 09:00；话费按已确认余额和固定月费估算 |

时间均为北京时间。单剧同季同日多集合并成一条通知，已看完、暂停、弃剧及归档不提醒；永久会员不提醒到期。各类可独立开关，系统关闭某类通道时会显示原因。点击通知进入对应栏目。删除或完成记录会取消对应排程，同一记录同一时间只发送一次。

提醒安排在本机系统，已同步记录可在锁屏、后台或断网时发送；电脑上修改后需打开手机同步。未允许“闹钟和提醒”时可能延迟；强行停止后需重新打开，厂商限制后台运行也可能影响通知。设置可查看最近同步、下次时间及每类待提醒数量。

## 纪念日桌面卡片

先打开 App 同步纪念日，再长按手机桌面，进入“小部件”，选择“七夜online → 纪念日倒数”。默认展示最近日期，右上角可固定选择某个纪念日；多张卡片可分别选择。卡片显示名称、目标公历日期及剩余天数，当天显示“今天”，单次倒数结束显示已过天数。点击卡片进入纪念日栏目。

公历与农历年度纪念日均换算真实目标日期；普通年度日期取最近未过的一次，明确年份的节假日和单次倒数不会擅自按年重复。桌面按北京时间换日刷新，无需每天打开网页计算天数；农历缓存覆盖本年及后两年，长期未打开 App 时会提示同步。卡片只保存必要展示信息，不保存完整备注或登录凭据。

## 独立测试账号

测试账号名为 `user`，使用单独配置的服务端密码。首次登录无记录；主账号云端、缓存和语音草稿保留在原空间，不合并到测试账号。切换账号时本机提醒、桌面卡片同步为当前账号。测试账号不连接主账号 TMDB 私人片单和评分，自己的观影记录照常保存。

## 升级与验证

1.1.2 及以上安装包支持打开后自动检查和下载新版，系统仍会要求确认安装；覆盖安装保留数据，不要先卸载。必须先发布 APK，再部署引用它的更新清单，避免下载地址不可用。

230项功能检查、正式网页构建、安卓编译及原签名验证通过。隔离浏览器已验证账号切换与空白测试空间、四类提醒的开关和跳转；原生模拟验证分类通道、送达去重、换账号清除通知，以及12种卡片尺寸与字号组合。当前未连接安卓真机，模拟通知与桌面渲染不代表具体手机已收到通知。
