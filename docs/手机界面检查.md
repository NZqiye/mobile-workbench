# 手机界面检查

检查日期：2026-11-07。范围为安卓安装版加载的网页和手机浏览器界面，以及安卓 1.1.3 的构建与签名；保留既有角色图标与八种主题。

## 单集截图、信息卡片与全剧百分比

依据用户最新两张安卓截图，单集图片由 64×42 放大到 112×63，320 像素窄屏为 96×54。截图按钮和观看勾选分离，点击展开宽 321 像素的大图，收起大图和简介都不会改变观看状态。大图保持16:9占位，在原始图片加载前布局稳定，TMDB w300缩略图放大时按需请求w780。

作品标题与操作改为同一行，“下一集”展示横向图片、日期、标题、季集。季列表的进度使用主题色文字，移除旧规则造成的整行粉色按钮底与不清晰数字，观看记录入口恢复透明背景，作品详情外框为16像素圆角。手机样例使用公开图片与隔离数据，不借用私人记录。

全剧汇总全部季的已看集数，当前季采用正在勾选的状态，其他季使用已保存记录。11/26显示42%，勾选第12集并保存后显示46%。未知总集数不展示全剧百分比；空进度0%、全看100%、重复与超出范围集数不虚增计数，多季合计使用实际总集数。各季同时显示自己的比例。

135项既有测试与2项新的百分比测试通过，正式构建通过。在320、393、844像素检查截图尺寸、标题换行、背景、季进度、记录展开、勾选保存和返回，无横向溢出。829集样例依然只渲染40集，可跳转700集、快捷保存、切段保留勾选、全选保存829集。此为浏览器模拟检查，未连接安卓真机。

## 1.1.3 观看进度与 App 通知

本轮界面修改位于“观影评分 → 作品 → 季 → 观看进度”，片单和推荐界面保持既有实现。使用 829 集隔离资料检查：手机只渲染当前 40 集，最后一段为 29 集；手机不再额外渲染隐藏的桌面 829 集列表。封面、标题、勾选框顶部对齐，单集简介默认折叠，展开不会误勾选。320、393、844 像素宽度下页面无横向溢出。

输入 700 可以直接定位第 700 集且不改观看状态；点“已看到这集”再快捷保存，实际本地记录为本季 1–700 集。输入超过总集数的 900 会提示有效集数，停止修改。跨段勾选后回到原段保持选中，全选并保存后为 829 集，既有“勾选代表连续看到该集”规则保留。

135 项测试通过，包括原生通知和录音请求并发、通知拒绝与重试、连接重置、北京时间映射、完成和删除任务，以及实际运行 Java 验证重复提醒、修改提醒时间和错过提醒的补发范围。安卓 1.1.3 编译和 v2/v3 签名验证通过，版本代码 5。网页正式构建通过。

通知设置用模拟安卓消息通道检查开启、拒绝后恢复、测试通知、设置入口和准时提醒入口；初始同步没有先发送空任务覆盖原生安排，完成任务后发送空列表移除提醒。通知打开“每日安排 → 计划安排”。通知设置在三种手机尺寸下无横向溢出。

本轮没有连接安卓真机。浏览器模拟和 Java 检查验证软件逻辑，系统授权窗口、重启恢复、锁屏通知到达和厂商省电策略需要在手机安装后确认。已实现本机到时提醒，尚未接入服务器即时远程推送。

用户追加的 App 时钟参考已实现并检查正式构建：393 像素宽度下表盘为 96 像素、时分字号 44 像素、秒数 24 像素；320 像素下对应收紧为 80、36、20 像素。表盘与数字整体居中，日期和星期可见，秒数每秒更新，秒数字色跟随主题，三种宽度均无横向溢出。

## 1.1.2 应用更新、评分空间与语音观影

正式构建后使用隔离浏览器资料检查 320、393、844 像素宽度。“应用更新”显示当前版本，按钮高度为 48 像素；检查中禁用重复点击，模拟原生状态可显示“已是最新版本”，失败后可重试，旧版提供下载入口。APK 使用相同正式证书，版本代码 4，v2/v3 签名校验通过。更新安全测试实际编译并运行 Java 的地址、清单和文件哈希校验，拒绝 HTTP、其他仓库、伪造主机、非标准端口及被修改的文件。

片单增加左右边距和行间距，海报为 56 × 84 像素，详情标题使用独立一行。手机 320 像素下标题文字宽度 248 像素，单集文字宽度 138 像素；393 像素下分别为 321 和 211 像素。长中文片名、长集名可换行，三种尺寸均无页面横向溢出。历史默认收起，查看按钮可展开。

观影常用语句的季数、中文/阿拉伯数字和昨日日期使用明确规则识别，已验证“看到第8集”与“看了第8集”的区别。浏览器模拟从原生 AAC 录音开始、停止、转写到保存，确认原作品第二季的前 8 集写入 `seasonProgress`，观看记录正确关联作品，撤销可恢复。此流程使用模拟录音和转写，未接触私人数据。131 项自动测试和正式构建通过。

未连接安卓真机；自动更新的系统安装窗口、实际麦克风与手机真实滑动表现仍需安装后验收。网页更新已发布时旧 App 可重开加载，原生自动更新功能必须先覆盖安装 1.1.2。

## 推荐、录入与 Markdown 备份

电视剧“为你推荐”采用横向单排封面，手机 320、393、844 像素宽度与电脑 1280 像素下均保持单排，页面本身不发生横向溢出。横向滑动、展开 60 条推荐、点击或键盘加入片单、鼠标和键盘展开简介已检查；打开简介不会误触加入。其他影视分类继续纵向展示，长标题与平台说明换行，空片单有明确提示。

秒钟更新已从整页分离；开发浏览器在片单稳定后观察 4.2 秒，观影组件无重复的父层刷新。手机推荐区移除背景模糊，图片异步解码，封面加载失败时保留高度。此前尝试的可见区域渲染与固定预估高度已移除：真实推荐检查发现卡片进入视口后，页面高度会由 7475 变为 7328 像素，可能造成滑动位置变化。内容工作区现为唯一的纵向滚动区域，卡片保持实际布局高度。

本次正式版本使用真实公开动漫资料和隔离片单检查，在 320、393、844 像素宽度下没有横向溢出，纵向推荐海报固定为 92 × 138 像素，片单海报为 64 × 96 像素。四倍 CPU 限速下连续五次模拟触摸滑动，滚动位置由 385 持续推进至 1925 像素，页面高度一直为 3792 像素。真实 Bangumi 海报成功加载；这些是本机 Edge 检查，不能代表安卓真机性能。

评分页默认隐藏添加搜索和同步工具，片单支持搜索、分类、展开已看完作品；添加工具可展开，季集勾选后能保存并返回片单。手机进入片单时不预加载未打开作品的详情。123 项自动测试通过，包括动漫真实图片尺寸选择和同作品备用海报资料保留。

模拟主海报返回 404 后，同作品真实 Bangumi 备用图成功加载；再使全部候选失败，片单占位仍为 64 × 96 像素。电影输入 8 分后成功保存独立观影记录。电脑 1280 像素下片单和添加工具可用，海报保持 48 × 72 像素。

快速记录标题与录音按钮中心差约 0.008 像素；时钟秒数仍持续变化。横竖屏切换保留当前影视栏目，不再自动跳回评分页。正式版本重新检查了圆角、窄屏榜单文字、简介操作和电脑布局。

Markdown 导出后，先用空备份清空隔离记录，再导入实际下载文件，任务、中文笔记、观影记录、纪念日、股票两类名单、饮水目标和删除的习惯编号均恢复。笔记中含代码围栏与格式标记时仍能恢复；云同步更新的时间和补齐的季信息依既有同步流程处理。普通 Markdown 与损坏文件报错且不写入记录；旧 JSON 仍可导入。原生下载通道另验证了 Markdown 文件名及中文内容完整传递。

线上浏览器推送的公开配置接口已返回 200，接收还需要用户在支持推送的浏览器中授权并订阅；安卓 1.1.0 没有原生锁屏推送。

## 安卓截图反馈后的修正

依据用户提供的四张安卓截图，针对主题选择、首页、天气和行情做了以下修正：

| 截图中的问题 | 处理方式 |
| --- | --- |
| 菜单与标题上下错位 | 菜单从固定定位改回标题栏布局，三个元素处于同一行，标题居中 |
| 主题名称、说明和“当前主题”被挤压 | 图片与色点放在上方，名称与说明使用完整宽度，状态放在固定位置；文字允许换行 |
| 行情价格底部被切掉 | 价格行高由内容决定，大字号保留完整字形，320 像素窄屏改为上下排布 |
| 宠物名称被省略，状态说明与名称争抢空间 | 名称和说明上下排列，均允许换行 |
| 天气信息贴边，部分模块仍呈直角 | 主模块使用 20 像素圆角、内部信息区 16 像素、表单 14 像素；天气增加内边距并分组换行 |
| 页面末尾可能被底部导航挡住 | 标题栏、滚动区和底部导航分成三行，内容末尾预留间距 |

检查覆盖 320、393、844 像素宽度，关键文字放大到 125% 后再次检查主题和行情。五天天气在窄屏下完整显示，设置页最后一排主题可滚动到导航栏上方。观影、股市、热榜、安排、饮食、资产、运动和目标页面均无横向溢出；电脑界面继续使用原布局。

正式构建通过，另用构建后的本地版本确认相同尺寸、圆角、文字空间、八种主题切换和页面末尾滚动。关键主题与价格文字在 320、393 像素宽度下放大 125% 仍完整可读。31 项行情刷新、拖动、分类与走势图相关测试通过。

字体使用手机系统无衬线字体和中文回退字体，保持中文与数字的行高一致，不额外下载字体文件。所有浏览器资料与行情为隔离检查数据，不代表实际行情；四张原始截图来自用户手机，本次修正后的验证仍是浏览器检查，未连接真机。
