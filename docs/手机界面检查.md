# 手机界面检查

检查日期：2026-11-07。范围为安卓安装版加载的网页和手机浏览器界面，以及安卓 1.1.1 的构建与签名；保留既有角色图标与八种主题。

## 推荐、录入与 Markdown 备份

电视剧“为你推荐”采用横向单排封面，手机 320、393、844 像素宽度与电脑 1280 像素下均保持单排，页面本身不发生横向溢出。横向滑动、展开 60 条推荐、点击或键盘加入片单、鼠标和键盘展开简介已检查；打开简介不会误触加入。其他影视分类继续纵向展示，长标题与平台说明换行，空片单有明确提示。

秒钟更新已从整页分离；开发浏览器在片单稳定后观察 4.2 秒，观影组件无重复的父层刷新。手机推荐区移除背景模糊，图片异步解码，封面加载失败时保留高度。此前尝试的可见区域渲染与固定预估高度已移除：真实推荐检查发现卡片进入视口后，页面高度会由 7475 变为 7328 像素，可能造成滑动位置变化。内容工作区现为唯一的纵向滚动区域，卡片保持实际布局高度。

本次正式版本使用真实公开动漫资料和隔离片单检查，在 320、393、844 像素宽度下没有横向溢出，纵向推荐海报固定为 92 × 138 像素，片单海报为 64 × 96 像素。四倍 CPU 限速下连续五次模拟触摸滑动，滚动位置由 385 持续推进至 1925 像素，页面高度一直为 3792 像素。真实 Bangumi 海报成功加载；这些是本机 Edge 检查，不能代表安卓真机性能。

评分页默认隐藏添加搜索和同步工具，片单支持搜索、分类、展开已看完作品；添加工具可展开，季集勾选后能保存并返回片单。手机进入片单时不预加载未打开作品的详情。123 项自动测试通过，包括动漫真实图片尺寸选择和同作品备用海报资料保留。

模拟主海报返回 404 后，同作品真实 Bangumi 备用图成功加载；再使全部候选失败，片单占位仍为 64 × 96 像素。电影输入 8 分后成功保存独立观影记录。电脑 1280 像素下片单和添加工具可用，海报保持 48 × 72 像素。

快速记录标题与录音按钮中心差约 0.008 像素；时钟秒数仍持续变化。横竖屏切换保留当前影视栏目，不再自动跳回评分页。正式版本重新检查了圆角、窄屏榜单文字、简介操作和电脑布局。

Markdown 导出后，先用空备份清空隔离记录，再导入实际下载文件，任务、中文笔记、观影记录、纪念日、股票两类名单、饮水目标和删除的习惯编号均恢复。笔记中含代码围栏与格式标记时仍能恢复；云同步更新的时间和补齐的季信息依既有同步流程处理。普通 Markdown 与损坏文件报错且不写入记录；旧 JSON 仍可导入。原生下载通道另验证了 Markdown 文件名及中文内容完整传递。

线上浏览器推送的公开配置接口已返回 200，接收还需要用户在支持推送的浏览器中授权并订阅；安卓 1.1.0 没有原生锁屏推送。

## 安卓截图反馈后的修正

依据用户提供的四张安卓截图，针对主题选择、首页、天气和行情做了以下修正：

| 截图中的问题 | 处理方式 |
| --- | --- |
| 菜单与标题上下错位 | 菜单从固定定位改回标题栏布局，三个元素处于同一行，标题居中 |
| 主题名称、说明和“当前主题”被挤压 | 图片与色点放在上方，名称与说明使用完整宽度，状态放在固定位置；文字允许换行 |
| 行情价格底部被切掉 | 价格行高由内容决定，大字号保留完整字形，320 像素窄屏改为上下排布 |
| 宠物名称被省略，状态说明与名称争抢空间 | 名称和说明上下排列，均允许换行 |
| 天气信息贴边，部分模块仍呈直角 | 主模块使用 20 像素圆角、内部信息区 16 像素、表单 14 像素；天气增加内边距并分组换行 |
| 页面末尾可能被底部导航挡住 | 标题栏、滚动区和底部导航分成三行，内容末尾预留间距 |

检查覆盖 320、393、844 像素宽度，关键文字放大到 125% 后再次检查主题和行情。五天天气在窄屏下完整显示，设置页最后一排主题可滚动到导航栏上方。观影、股市、热榜、安排、饮食、资产、运动和目标页面均无横向溢出；电脑界面继续使用原布局。

正式构建通过，另用构建后的本地版本确认相同尺寸、圆角、文字空间、八种主题切换和页面末尾滚动。关键主题与价格文字在 320、393 像素宽度下放大 125% 仍完整可读。31 项行情刷新、拖动、分类与走势图相关测试通过。

字体使用手机系统无衬线字体和中文回退字体，保持中文与数字的行高一致，不额外下载字体文件。所有浏览器资料与行情为隔离检查数据，不代表实际行情；四张原始截图来自用户手机，本次修正后的验证仍是浏览器检查，未连接真机。

## 账号与观影检查

| 发现的问题 | 已处理 |
| --- | --- |
| 账号、同步、手机同步分散，重复解释操作 | 合并为一个个人账号入口，登录后自动同步，备份独立保留 |
| 本地旧解锁标记可能让未有效登录的设备显示在线 | 启动时服务器校验 Cookie，失败可重试，本机记录保留 |
| 时钟靠左且安卓隐藏秒数 | 时钟组居中，显示时、分、秒 |
| 单集封面和文字的列位置冲突，集名被挤窄或截断 | 明确封面、文字、勾选各列位置，标题换行、简介可读，整行可勾选 |
| 电影评分缺少专用布局 | 封面与评分表单并排，表单留出间距，保存按钮至少 48 像素高 |
| 安卓设置显示无法使用的浏览器通知按钮 | 展示准确能力说明，安卓不显示浏览器推送开关 |
| 分时图下方小字过多 | 删除操作提示及来源小字，保留实时读数和图表操作 |

浏览器检查使用隔离的账号、影视资料和行情数据，不读写私人云端记录。单集在 320、390、844 像素宽度下检查文字空间和横向溢出，并验证勾选、保存观看进度与电影评分界面。账号检查覆盖错误密码、登录合并、退出失败恢复和本机记录保留；两类股票名单仍包含在同步和备份中。

安装版通过系统 WebView 加载线上网页，因此现有 1.1.0 可直接加载本次界面更新；首页返回键直接退到后台需覆盖安装 1.1.1。新 APK 已完成编译、v2/v3 签名验证，沿用原证书和应用标识。未连接安卓真机，不能将浏览器模拟通道检查视为系统麦克风、键盘、返回键或锁屏通知验收。原生锁屏推送尚未实现；浏览器推送需要服务器配置和通知权限，目前每天北京时间 10:00、15:00 检查到期事项。
