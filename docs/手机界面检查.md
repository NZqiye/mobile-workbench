# 手机界面检查

检查日期：2026-11-07。范围为安卓 1.1.0 加载的网页和手机浏览器界面；保留既有角色图标与八种主题。

| 发现的问题 | 已处理 |
| --- | --- |
| 账号、同步、手机同步分散，重复解释操作 | 合并为一个个人账号入口，登录后自动同步，备份独立保留 |
| 本地旧解锁标记可能让未有效登录的设备显示在线 | 启动时服务器校验 Cookie，失败可重试，本机记录保留 |
| 时钟靠左且安卓隐藏秒数 | 时钟组居中，显示时、分、秒 |
| 单集封面和文字的列位置冲突，集名被挤窄或截断 | 明确封面、文字、勾选各列位置，标题换行、简介可读，整行可勾选 |
| 电影评分缺少专用布局 | 封面与评分表单并排，表单留出间距，保存按钮至少 48 像素高 |
| 安卓设置显示无法使用的浏览器通知按钮 | 展示准确能力说明，安卓不显示浏览器推送开关 |
| 分时图下方小字过多 | 删除操作提示及来源小字，保留实时读数和图表操作 |

浏览器检查使用隔离的账号、影视资料和行情数据，不读写私人云端记录。单集在 320、390、844 像素宽度下检查文字空间和横向溢出，并验证勾选、保存观看进度与电影评分界面。账号检查覆盖错误密码、登录合并、退出失败恢复和本机记录保留；两类股票名单仍包含在同步和备份中。

安装版通过系统 WebView 加载线上网页，因此现有 1.1.0 可直接加载本次界面更新。未连接安卓真机，不能将浏览器模拟通道检查视为系统麦克风、键盘或锁屏通知验收。原生锁屏推送尚未实现；浏览器推送需要服务器配置和通知权限，目前每天北京时间 10:00、15:00 检查到期事项。
