# 股市行情移动优化

日期：2026-11-05。状态：本地实现与验证完成，尚未发布线上。

用户要求优化“股市行情移动的逻辑”。结合页面现有左侧把手，本次范围为自选行情列表的拖动排序。保留原有图标、主题变化、股票数据及行情刷新方式。

## 调整后的操作

- 按住股票左侧把手，上下移动超过6px后进入拖动；轻点和小幅晃动不改变顺序。
- 股票跟随鼠标或手指移动，越过相邻行的中间位置后换位，并留4px缓冲，减少在边界附近来回跳动。
- 拖动接近可见区域上下边缘时，滚动实际承载列表的容器；越接近边缘，滚动越快。
- 松手保存当前顺序；移动后回到原位置不重复保存。
- 触摸中断、失去指针捕获或按 Esc 时，恢复拖动前的顺序，并保留期间刷新的价格。
- 只响应发起拖动的那根手指；上下方向键仍可逐项调整顺序。
- 暂时没有返回行情的自选项保持其原有位置，不因移动其他股票而被挪到末尾。

触摸拖动仅从把手开始，股票内容区域仍可正常上下滑动。

## 实现范围

`app/page.jsx` 的 MarketBoard：指针状态、换位判断、自动滚动、结束/取消与顺序保存。`app/globals.css` 仅调整拖动中的跟随位移及层级，没有修改主题配色。

## 验证

- 15项行情交互测试通过，覆盖误触、多指输入、边界抖动、取消、刷新并发、缺失行情项位置、重新进入与缓存顺序。
- Edge 浏览器实际鼠标输入：轻点、拖动、松手保存、方向键与 Esc 取消通过。
- Edge 浏览器触摸输入模拟：边缘自动滚动、松手保存、触摸取消与刷新保留顺序通过。
- 生产构建与差异空白检查通过。

测试使用独立浏览器存储和模拟行情，没有修改用户浏览器中的自选股票。手机验证使用浏览器触摸输入模拟，尚未在实体手机上检查手感。

证据文件位于 `output/playwright/marketMoveVerification.json`、`market-move-active-desktop.png` 与 `market-move-active-mobile.png`。
