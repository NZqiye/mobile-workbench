# 基金卡片底部排版优化

日期：2026-11-05

将共用基金卡片底部的连续小字改为三项独立信息：持有份额、投入金额、参考净值。三栏各占三分之一宽度，标签和数值居中排列，使用统一字号、行高及等宽数字。

四个操作按钮等宽铺满整行，保持 44 像素触摸高度。定投、校准和卖出采用普通文字颜色，删除保留红色提示。支付宝校准日期独立居中显示，不再挤进数据串。

保留八种主题配色以及持仓、交易和估值计算。投入金额继续显示原先的净投入金额；参考净值继续采用估值优先、实际净值兜底的原有口径。

验证通过：

- 320、390、514、1440 像素下，三栏信息和四个按钮均分宽度，标签与数值对齐，卡片无横向溢出。较长金额允许换行，完整保留数值。
- 零持仓、已有持仓、较大金额及支付宝校准日期均正常展示。
- 八种主题的标签、数值和按钮文字保持可读。
- 定投、校准和卖出正常打开原有表单，切换表单不修改持仓。键盘焦点及删除操作正常。
- 现有 15 项行情交互测试、最终生产构建及差异空白检查通过。

浏览器验证使用独立测试会话和固定行情数据，未更改用户真实浏览器的基金持仓。
